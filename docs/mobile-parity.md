# 手机端对齐

窄屏 web（`web/src/mobile`，何时用它见 `web/ui/src/parts.tsx` 的 `NARROW`）的设计。2026-09-30 到 10-23 安卓 app（当时是 Kotlin 写的）逐屏照它对齐；现在的 app（`apps/mbui`，每个设备上同一个 app）按 `apps/mbui/docs/architecture.md` 设计页面：这里的规则读来是为了知道为什么，不照抄。两边都要能做电脑版能做的事。

布局看宽度，交互看输入方式：窄屏是布局，触控是交互，两者分开判断。只有「用手机版还是电脑版」这一处两者一起看：竖着且不宽于 700px 的屏幕，或者长宽都不超过 1024px 的触控屏（横过来的手机、展开的折叠屏）用手机版；不窄于 680px 时（展开的折叠屏、横过来的手机）页面收成居中的一列（最宽 680，两边至少留 72）；会话列表平时收起：屏幕左下角有一个和输入框等高、底边对齐的按钮，点开从按钮处弹出「最近的会话」（前 6 个，头部可新建，底部「全部会话」回列表），选一个就替换当前打开的会话；下方栏（见下）在这一列的正中，和手机上一样宽。手机和平板上的 app（mbui，安卓和 iOS）不用 680 自己判断，按系统给的尺寸档和铰链：宽高都是 regular（iOS 的 size class；安卓的 WindowSizeClass，medium 及以上；iPhone Duo 内屏、iPad、展开的安卓折叠屏）用电脑版的结构（图标栏 + 会话列表 + 页面，手机主题和手势），折痕竖着时侧栏右边缘对齐折痕；只有宽度 regular（横过来的手机）用上面这套居中一列加左下角按钮的排版；和别的 app 并排分屏成 compact 时变回手机版。折叠屏半开、折痕横着（笔记本姿态）时，会话页铺满屏，消息停在折痕上方，折痕下方是输入框，再下面是最近会话。iPhone Duo 外屏的状态栏在右侧一竖条，页面让开它。手机页面的顶栏下面不画分割线，只靠磨砂和内容区分（2026-10-24）。

## 下方栏

各「地方」（对话、文件、Station、Profile、连接、用量、已归档）的首页底下浮着一条下方栏（web `mobile/Bar.tsx`，app `apps/mbui/src/sfapp/bar.mbt`），点一格就原地换到那个地方的首页（不推新页，没有返回）；推进来的页面上它让开。这台设备可以设好几栏、每栏最多 4 个（core prefs `bars`，「设置 · 下方栏」里改），不止一栏时在栏上往上一划，面板长出来列出其他栏，划到哪个上松手就换到那栏、进那个地方。令（新建对话）在对话、已归档的首页上嵌在栏顶正中的缺口里。全部是磨砂玻璃，各端一样。默认两栏：对话、文件、Profile、Station；用量、连接、已归档。Station 的图标、红点和读屏文字就是原来首页右上角那个（首页右上角不再有，只有没下方栏的安卓宽屏还留着）。

下方栏的各个地方（文件、Station、Profile、连接、用量、已归档）是和对话列表一样的主页面：首页那样的磨砂顶栏（齿轮进设置、页面名、这页别的操作），没有返回、大标题和开头的说明；设置里的入口只是另一条路，从那里进去是普通子页面（返回、居中标题）。栏顶缺口放这页的主要操作：对话、已归档是令；Station、文件（管理员）和 Profile、连接（有在线 station）是「＋」；没有的（用量）缺口合上。切换地方时新页面朝球走的方向滑进 30 并淡入；切走的页面留着，切回来停在原来的滚动位置。文件的列表是电脑侧栏那种平铺的两行行（文件夹图标、名字、行尾 station 和圆点），Station、Profile、连接暂时还是卡片（2026-10-16 用户定）；连接的「全部/我建的」是顶栏右边的筛选菜单；Profile、连接、用量、已归档列表为空时空状态里说这页是什么。

## 交互：触控和鼠标

判断：`(pointer: coarse)` 为触控，`(hover: hover) and (pointer: fine)` 为鼠标。宽屏和窄屏都可能是任意一种（窄窗口用鼠标、平板横屏用手指）。

| | 触控 | 鼠标 |
|---|---|---|
| 消息的引用、拷贝 | 长按出菜单 | 选中文字出「引用」；右键出菜单 |
| 返回 | 从左边缘右滑返回 | 返回按钮、浏览器后退 |
| 底部面板 | 拖动把手，或在面板顶部下拉关闭 | 点遮罩或 Esc 关闭，滚轮滚动 |
| 发送 | 按发送按钮（回车换行） | Enter 发送，Shift+Enter 换行 |
| 提示 | 没有悬停提示；需要的说明直接写出来或长按看 | 悬停提示 |
| 点按区域 | 不小于 44×44 | 按视觉大小 |
| 列表行 | 按下有反馈，长按看时间 | 悬停高亮，时间常显 |

## 功能差距（电脑版有、手机端缺）

每一项在 app 和窄屏 web 都要补上，两边都补完才勾掉；只补了一边的注明是哪边。

### 会话列表
- [x] 已归档的对话：恢复到列表、删除（电脑版在列表的筛选菜单里；手机从列表顶栏的归档按钮打开）

### 对话
- [x] 在 Slack 里打开（对话来自 Slack 时）
- [x] 预览 station 上的网页服务（电脑版侧栏的 localhost 预览；手机从顶栏的服务按钮或 agent 名片的「后台」打开，全屏）
- [x] 执行历史里正在进行的步骤（两边都是一行一步）
- [x] 多个 agent 的执行历史之间切换（电脑版是标签页；手机点 agent 的名字、顶栏的 agent 标记或对话信息里的 agent，先出它的名片，「历史」一行进执行历史；点正在做的那行活动直接进）
- [x] 粘贴图片、拖入文件（鼠标，只在 web）

### 设置 · 账号
