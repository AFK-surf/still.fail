# 手机端对齐

窄屏 web（`web/src/mobile`，何时用它见 `web/src/ui.tsx` 的 `NARROW`）和 Android app 是同一个界面。2026-09-30 起以窄屏 web 为准：web 手机版先做，Android 逐屏照它对齐（布局、字号、颜色、图标、文案、交互）。两边都要能做电脑版能做的事。

布局看宽度，交互看输入方式：窄屏是布局，触控是交互，两者分开判断。只有「用手机版还是电脑版」这一处两者一起看：竖着且不宽于 700px 的屏幕，或者长宽都不超过 1024px 的触控屏（横过来的手机、展开的折叠屏）用手机版；宽于 720px 时手机版收成居中的一列。

## 交互：触控和鼠标

判断：`(pointer: coarse)` 为触控，`(hover: hover) and (pointer: fine)` 为鼠标。宽屏和窄屏都可能是任意一种（窄窗口用鼠标、平板横屏用手指）。

| | 触控 | 鼠标 |
|---|---|---|
| 消息的引用、拷贝 | 长按出菜单 | 选中文字出「引用」；右键出菜单 |
| 返回 | 从左边缘右滑返回 | 返回按钮、浏览器后退 |
| 底部面板 | 拖动把手，或在面板顶部下拉关闭 | 点遮罩或 Esc 关闭，滚轮滚动 |
| 发送 | 按发送按钮（回车换行） | Enter 发送，Shift+Enter 换行 |
| 提示 | 没有悬停提示；需要的说明直接写出来或长按看 | 悬停提示 |
| 点按区域 | 不小于 44×44 | 按视觉大小 |
| 列表行 | 按下有反馈，长按看时间 | 悬停高亮，时间常显 |

## 功能差距（电脑版有、手机端缺）

- [x] 在 Slack 里打开（对话来自 Slack 时）
