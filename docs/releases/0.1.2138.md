- 新功能：⌘K 和手机对话列表顶上的搜索框能搜到消息内容（中文也行），点结果直接跳到那条消息
- 新功能：Profile 可以直接用服务商的 API key 添加（OpenAI、DeepSeek、Qwen、Kimi、OpenRouter、Groq 等），按厂商、中转站、云上托管、本地分组挑选
- 新功能：Profile 和 skill 可以分享给 workspace 里的其他 station；同一个账号在几台 station 上只显示一行，下面列出登录了它的每台 station
- 新功能：自动决策：用现有 Profile 里的模型，在 agent 说完成后判断这个 chat 还有没有后续事项，没有就标「推荐归档」；判断依据是可以编辑的「归档策略」
- 新功能：agent 可以给另一个 chat 的 agent 发消息；agent 在 Slack 里收发的消息也会显示在 chat 里
- 新功能：workspace 的 owner 和管理员可以加自己部署的中继，station 和成员设备会一起用、自动选最快的
- 新功能：上传文件的上限从 50 MB 提高到 1 GB，显示进度，断线后接着传
- 新功能：安卓设置里新增「本机缓存」，可以按 chat 查看和清除占用的空间
- 改进：station 换成新实现，升级和重启时正在跑的 agent 不中断
- 改进：网页、桌面和安卓的客户端核心换成新实现，打开更快，离线时直接显示上次的内容；网页多开标签页时只有一个在同步
- 改进：本机缓存有上限（每个账号 256 MB），超了先清最久没看的，打开时再拉回来
- 改进：大视频不再整份下载，station 会生成封面；大文件分块下载
- 改进：奏：拿到的决策马上显示，推荐选项用主题色，选完收起成「谁选了什么」一行；直接发消息回答也会立刻收起
- 改进：电脑上设置页、菜单和弹窗换了新样式（浅灰卡片、磨砂底），对话标题单击就能改名
- 改进：对话顶部的 station 更新提示会写明是哪台 station、版本和进度
- 修复：打开有未读的 chat 停在「以下是新消息」，跳到某条消息时顶部对齐标题栏
- 修复：置顶、改名、回答决策后列表行和选项不再先变、变回、再变
- 修复：手机休眠一会儿再打开时偶尔被退出登录
- 修复：手机上 station 重连或上下线时卡片和页面上下跳动，重连时也不再丢掉已有内容
- 修复：安卓下载更新包时网络一断就失败，现在会自动重试并接着下
- 修复：安卓打开 Profile 页闪退、在含中文的地方搜索闪退、内联 HTML 卡片闪烁，以及发消息时的跳动和卡在输入框
- 修复：深色模式下代码块、表格的底色偏红
