- 新功能：桌面版有右键菜单了：可以复制图片（原图）、链接和选中的文字，输入框里可以剪切、粘贴
- 新功能：图片预览的顶栏加了「复制」按钮，复制的是原图
- 改进：选连接线路时同时看延迟和传输速度，海外的 station 不再总停在北京中继，安卓上也能测出各中继的延迟、换到更快的线路
- 改进：新会话优先分到周额度快重置、剩余额度会作废的账号，不再在几个账号间轮流分
- 改进：agent 换账号后开新会话，按需读回之前的记录，不再把整段对话重新读一遍；执行历史前后接着显示
- 改进：发送带附件的消息时，附件从输入框飞进消息里，只发图片或文件也有发送动效
- 改进：不同 workspace 的列表过滤选项（全部 / 我参与的 / 监控中）各自记住
- 修复：Slack 消息里的截图和文件现在会交给 agent；Slack app 没开「读写文件」权限时会注明文件没拿到
- 修复：执行历史里 agent 发的消息有时排错位置、重连后顺序错乱或重复；展开一组步骤时，思考和工具调用按实际顺序穿插显示
- 修复：Mac 上 station 每次更新后反复弹「允许查找本地网络设备」
- 修复：重启桌面 app 或重新打开网页时回到上次的 workspace；离开、删除 workspace 或退出账号后不再先跳回它再报错
- 修复：会话列表在切换布局、打开页面时整列弹一下；手机上开关搜索时搜索框和列表的跳动
- 修复：新建 chat 刚开始时误显示「没说一声就停了」；发消息时消息流中间闪出转圈
- 修复：共享调试配对时，配对码改成通知里填，不用离开设置，配对窗口不会被关掉
- 修复：等待超过一小时时，时长显示成一长串小数
- 修复：安卓切换 workspace 时列表闪一下；执行历史里命令只显示半行；点开一条后按返回把下面的页面退了
