- 新功能：Mac 桌面版在屏幕右边缘常驻一个液态玻璃半球：有新消息或等你决定时冒出来，鼠标移上去就能看消息、选选项或标为已读；「设置 → 通知」里可以开关浮窗、冒出提醒，以及要不要放普通未读
- 新功能：桌面 app 的 Dock 图标显示需要你处理或有未读消息的聊天数
- 新功能：可以用邮箱和密码登录（只给预设的审核账号用）
- 新功能：agent 读其他 station 上的聊天时能看到里面的图片和文件；session_send 给其他会话发消息也能带文件
- 新功能：输入框里还没发出的图片，点缩略图就能全屏预览
- 改进：会话运行中也能切换账号、模型和思考深度，下一轮自动生效
- 改进：连接 station 时同时经所有中继连，按实测往返选线路，慢的读请求自动改走另一条，不再频繁来回切换；鼠标停在 station 卡片的连接信息上能看到每条线路的延迟和正在用哪条
- 改进：去掉滚到底部时其它消息变淡的效果
- 修复：海外 station（如东京）在国内手机上连不上：新增经北京入口转到香港中继的线路，自动选用
- 修复：某条中继线路变差时（如北京到东京丢包），手机和网页连不上 station
- 修复：chat 换到新的运行会话（换账号或续接失败）后，执行历史不再更新、之前的部分也可能缺失
