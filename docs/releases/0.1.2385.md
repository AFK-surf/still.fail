- 新功能：station 可以设图标：still.fail 自带的图标、任意 emoji，或上传一张图片
- 新功能：鼠标停在聊天里的 agent 头像上，显示它的状态、花费、缓存命中率、上下文和账号额度
- 新功能：手机网页下拉聊天列表可以重新加载页面，登录或加载卡住时会出现「重新加载」
- 改进：网络差或延迟高时快很多：数据压缩后再传，断线重连只补错过的变化，列表只下载变了的部分，执行历史先收每一步的摘要、点开时再读完整内容，后台同步聊天记录打包读取，图片缩略图和视频封面存在本机
- 改进：新登录的账号自动启用同类账号已经启用的模型；已知过时的模型（如 Opus 5、Sonnet 4.6、GPT-6 Sol）自动换成同系列的新版，之后手动勾回的不再动
- 改进：决策选项合成一张卡片，每项带序号，推荐项的序号用主题色
- 改进：手机新建对话页的内容从选择器和输入框下面滑过，底部是一整条磨砂；「令」图标更清晰
- 改进：安卓只在新版本有安卓上的改动时才在首页提示更新，其他版本在设置 → 版本里仍可更新；更新日志里桌面版、station 的改动不再出现在安卓的「已更新」里
- 修复：手机连 station 经常连不上、连上了容易断、消息发不出去；有设备连到一半掉线时，station 有一阵谁都连不上
- 修复：agent 发的消息偶尔只在列表里出现，chat 里要等下一条消息才出来
- 修复：正在用的 Profile 也能删除，用它的会话会换到别的 Profile，换不了就停下
- 修复：Mac 上 Claude 钥匙串读不到时，不再误用旧的登录凭据
- 修复：命令较长时，agent 正在做的事的描述被截掉一半
- 修复：消息里直接贴的网址可以点开了（不会把后面的中文算进链接），长按链接可以复制或打开
- 修复：iPhone 上加到主屏幕的网页版登录后卡在「正在登录…」、顶上状态栏是白的，执行详情里的中文标签被拆成一字一行；手机网页版 Profile 菜单、环境变量和分享设置报站点地址错误
- 修复：安卓输入框里待发的图片点一下就能放大查看，点图中间不会再误删
- 修复：Slack 来的和已归档的 chat 打开时不再自动展开执行历史
- 修复：桌面侧栏的状态图标和圆点对齐、「监控中」用自己的眼睛图标；弹出列表的滚动条不再伸出圆角；「Needs you」提示条完整换行显示；侧边栏标签多了不再折成好几行
