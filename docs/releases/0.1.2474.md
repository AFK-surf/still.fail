- 新功能：Windows 桌面客户端（安装包暂未签名，首次运行 Windows 会提示「未知发布者」）
- 新功能：Windows 可以在 WSL 里装 station，登录 Windows 后自动保持在线
- 新功能：agent 可以给一件事另开一个 chat（本机或别的 station），每轮结束时自动告诉开它的 agent
- 改进：station 生成对话列表、会话列表和任务列表快了好几倍；机器被 agent 的任务占满时，station 回应和推送不再被拖慢
- 改进：开着 app 时，station 也会在没有 agent 运行、几分钟没人操作时自动更新
- 改进：电脑上鼠标移到对话标题栏的 agent 头像上，显示它在做什么、已运行多久，可以单独停止；点头像打开它的执行历史，右侧面板只保留一个执行历史标签；对话里有多个 agent 时，可以在「在干活」那一行只停其中一个
- 改进：决策的提示更轻：chat 列表里只作提示，chat 里输入框上方的铃铛按钮跳到待决策的消息，待决策的消息下面可以直接点「忽略」
- 改进：手机网页滚动、输入、发送和滑动返回更流畅，边缘返回逐帧跟随手指
- 改进：更新日志按端分成 tab（桌面、网页、安卓、Station、云端），默认只看当前 app 的，每条前面标出修复、改进、新功能
- 改进：聊天顶部 station 的悬浮卡片重新排版，机器信息不再从中间断开，网络和进程内存分区显示
- 改进：安卓聊天页点一下或拖动消息列表就收起键盘，写了一半的内容会保留
- 修复：station 明明连得上时，agent 的新消息要等它再发一条才显示
- 修复：station 上某个已归档 chat 的存档文件丢失时，整个 chat 列表跟着读不出来；恢复后已连着的客户端也会自己重读
- 修复：消息里的文件路径按原样显示、可以复制完整路径，悬浮卡显示完整路径和目录内容，本机文件可以在 Finder 中显示
- 修复：桌面端点了更新、重启后马上又提示更新
- 修复：英文界面里残留的中文都换成了英文，两处显示成 key 的文字也修好了
- 修复：很长的提示不再超出窗口；左下角「正在等待」的列表把相同的请求合成一行，对话右上角的服务和任务太多时可以滚动
- 修复：手机网页边缘返回不再叠加浏览器动画，取消滑动不会误触按钮，松手后从当前位置继续
- 修复：输入框有光标时，点「要你帮忙」条的忽略第一下就生效；决策卡片悬停最后一项时底部露出深色带；侧栏底部「在跑 N」和 station 状态没对齐
