- 新功能：电脑上左边多了一列侧边条，对话、文件、Station、Profile、连接、用量一点就到，右键可以自定义放哪些、什么顺序，底部能切换 workspace、看到各 workspace 的新消息；侧栏点边缘就能收起，收起后鼠标移到图标上会滑出来
- 新功能：手机上（网页和安卓）加了下方栏，对话、奏、文件、Station 等地方一点就到；可以设好几栏，往上一划就能换
- 新功能：station 可以把指定的文件夹开放给 workspace 成员浏览、阅读、播放、上传和整理；在「文件」里选文件夹，先列常用位置和外接硬盘，没权限读的会提示怎么开
- 新功能：chat 可以公开分享：在「对话信息」里生成一条链接，拿到链接的人在浏览器里就能看，附件可以逐条选带不带；内容只存在 station 上，发布前会隐藏疑似密钥，随时可以撤销
- 新功能：在对话里 @ 其他 workspace 的对话，确认后自动分享给这个 workspace，这里的 agent 就能读到它
- 新功能：⌘F 在当前对话里查找，没加载的历史消息也能搜到；手机上在对话的「…」里查找
- 新功能：workspace 可以设图标；station 的自带图标从 48 个加到 314 个，可以选颜色，能用中英文搜索
- 新功能：设置里的「本机 Station」页，管理这台电脑上的 station（包括单独安装的）
- 新功能：网页版侧边条有「下载客户端」，可以下载 Mac、Windows、Android 客户端
- 新功能：只在 Slack 里的会话空闲 3 天后自动归档
- 新功能：station 的盘快满时提醒 agent 清理，满了先暂停 agent 正在跑的命令；内存吃紧时结束占用最多的那个命令，不再连 station 一起拖垮
- 新功能：安全模式下有新设备等你确认时，直接弹出核对短码的窗口
- 改进：长对话和执行历史只渲染看得见的部分，打开对话、切换对话、开侧栏和执行历史都不再卡
- 改进：agent 头像卡片（电脑悬停、手机点名字）显示状态和时长、最近几步、费用、缓存命中、上下文和账号额度；执行历史的详情改成费用、缓存命中、上下文三个大数字
- 改进：电脑上的 Station 和 Profile 改成左边列表、右边详情；Profile 详情里有近 7 天的费用、调用和 token；station 设备信息统一写「芯片 · 内存 · 系统」，CPU、内存、磁盘按剩多少显示
- 改进：输入框可以展开显示更多文字，长段粘贴自动变成可预览的文字附件；安卓粘贴 chat 链接变成引用，粘贴的图片作为附件上传
- 改进：电脑上的小说阅读器和视频播放器工具栏常驻，阅读器有目录、搜索和排版，视频有音量、选集和进度预览；夜间模式跟着 app 走
- 改进：workspace 菜单改成固定顺序的列表，⌃1…⌃9 直接切换
- 改进：桌面版可以拖着对话标题移动窗口；更新提示改成左下角的气泡；Windows 版左上角不再给 macOS 窗口按钮留白
- 改进：菜单、弹窗、卡片和 ⌘K 的背景、边距和圆角统一，圆角改成平滑圆角，勾选框和滚动条换成 app 自己的样式
- 改进：chat 列表里最后一条消息的摘要不再显示 Markdown 原文；Slack 消息的来源和去向跟在名字后面
