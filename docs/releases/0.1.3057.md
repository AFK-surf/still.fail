- 新功能：「文件」可以浏览整台机器，常用文件夹 pin 到侧栏，可以切换分栏、文件树和列表三种视图；chat 右侧可以打开文件，拖进输入框默认发路径，也能改成发文件
- 新功能：通知设置按手机系统的样子重做，顶上有预览，横幅、红点、桌面浮窗可以按类别分别设；设置里新增「权限」页，系统没给通知权限时会提示，点一下就去系统设置打开
- 改进：记忆页改成目录，全局记忆按小节列出、每个项目一行，点开单独阅读
- 改进：手机上的「已归档」可以点开对话、搜索，长列表分批加载
- 改进：安卓上打开过的文件存在手机上，再打开不用重新下载
- 改进：电脑侧边条的 tab、各侧栏开没开和宽度，手机下方栏的设置，都按 workspace 分别记住；侧栏临时展开时把页面推开，不再盖住
- 改进：安卓下方栏上滑换栏全程跟手，过了高度就展开、回落就收起，换栏不再闪烁
- 改进：对话顶部的 station 显示直连、中继或离线，agent 状态移到 agent 图标上；机器资源按「已用」填充，越满越紧张
- 改进：电脑上打开图片、PDF、文本、视频的顶栏统一；chat 里的文本和视频附件也用同一个阅读器和播放器打开，跟随外观设置
- 改进：有 agent 在工作时页面不再每帧重绘，更省电
- 修复：点通知会打开对应的 chat 并跳到那条消息（安卓、桌面和网页）
- 修复：安卓上聊天里有内嵌 HTML 预览时频繁闪退
- 修复：station 更新时偶尔会断开一分半钟左右才恢复
- 修复：网络刚切换后连接又断开时，偶尔有一次读取报「连接断开」
- 修复：不能预览的附件点开后不再先下载整个文件；下载大文件时进度条连续走，不再一跳一跳
- 修复：回复决策后聊天列表跳动；发消息后 agent 的「正在…」那行抢在自己的消息前面出现
- 修复：鼠标停在屏幕右边缘时桌面浮窗反复弹出收回；多块屏幕时浮窗放在最右边那块屏
- 修复：共享调试配对时安卓可以自动读取配对码
- 修复：⌘K、阅读器、视频控制条、文件卡片等处的圆角和按钮对齐，⌘K 鼠标停在底部时列表自己往下滚
