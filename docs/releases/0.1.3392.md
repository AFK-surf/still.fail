- 新功能：可以用邮箱验证码登录和注册，不再只能用 Google 账号
- 新功能：一台 station 可以同时加入多个 workspace（「添加 station」里选「已有的 station」），各 workspace 的对话、记忆、Slack 和文件夹分开；开了安全模式的 station 也能加入开了安全模式的 workspace
- 新功能：station 页新增「屏幕」：在电脑、手机网页和安卓上远程查看和操作 station 的桌面和它的浏览器标签页，剪贴板两边互通，可以把文件传过去；有人在控制时先「只看」，点「接管」接过来
- 新功能：station 页新增「权限」：看这台 Mac 给 still.fail Helper 授了哪些权限、缺什么，点「申请」弹出授权窗口；远程屏幕和「文件」读文稿、桌面、下载、外接盘都由 Helper 拿授权，更新后不用重新授权
- 新功能：密钥库：token、API key、SSH 密钥存在「密钥」里给 agent 用，agent 申请时在客户端批准，看不到明文；开了安全模式时只在你的设备上解密；每条密钥可查看使用记录
- 新功能：agent 能力：用 station 自己的 Chrome（登录状态会保留）、自己截图操作屏幕、在 station 上发起命令行工具的登录（你在卡片上点「复制并打开」用自己的浏览器登录）、直接用其他 station 上的本地服务或把端口转发过来、按各台 station 的负载挑机器跑任务
- 新功能：DeepSeek Harness（dsh）可以作为 agent 的运行时，DeepSeek、Kimi、Qwen 等只有 OpenAI 兼容接口的服务商也能用
- 新功能：从别的 app 分享链接到 still.fail（安卓的分享菜单，装到桌面的网页版也行），选一个 chat，链接以卡片放进输入框
- 新功能：文件浏览器改成 Finder 的操作方式：单击选中、双击打开、键盘操作、原地重命名、拖动移动或上传、排序和显示隐藏文件；安卓支持长按多选、批量下载和删除、文件夹打包下载；手机和桌面新对话里都能把 station 上的文件发进对话
- 新功能：执行历史按一轮一轮分开，发出去的消息最显眼，可以「只看收发」隐藏工具步骤
- 新功能：设置 › 外观 可以减少动画（跟随系统 / 减少 / 不减少）
- 改进：关闭安全模式前要逐条确认后果、输入 workspace 名称，再用 Touch ID、指纹或屏幕锁验证本人；安全模式的说法改成「受信任设备」「批准」「安全码」，未受信任的设备会自动请求信任
- 改进：分享给其他 workspace 的对话连续 6 小时没被读写就失效，要重新分享
- 改进：各端的加载状态统一，读取时显示内容的轮廓和正在读哪台 station；界面文案更简洁
- 改进：上传附件时进度连续走，发出后还在上传的也显示百分比
- 改进：安卓点通知进 chat 时新消息已经在手机上，不用再等
- 修复：手机和 station 在同一局域网时常常走中继，现在几秒内切到直连，也不再掉回中继
- 修复：Mac 上的 station 启动时或运行中内存占用冲到 1 GB 以上
- 修复：station 重启时偶尔有一次读取报「连接断开」；共享调试在手机切换网络后偶尔收不到回应
- 修复：执行历史里 station 的通知显示成「来自 ember 的消息」和原始英文
- 修复：电脑上竖屏视频上下显示不全；chat 里的视频附件恢复逐帧查看、放大、取色和存帧
- 修复：安卓新建 chat 和草稿里的图片先显示成文件卡片；发送图片时动效里的图片和消息里的不一致
- 修复：跳到较早的消息时没有高亮；侧栏临时展开时对话内容重新排版；文件浏览器进出文件夹时丢了滚动位置
