- 新功能：⌘K 和手机的搜索可以搜整个 workspace：所有对话（包括已归档的）、消息、文件、服务、station 和成员，各台 station 一起搜；也能搜到 station 机器上的文件（Mac 用 Spotlight），邮件、备忘录等个人数据默认不搜
- 新功能：选模型时能看到 workspace 里所有 station 的模型，别的 station 的标出来源，点一下可以借用
- 新功能：station 页可以设置 Agent 环境变量（比如 HTTP 代理），Claude Code、Codex 和后台任务启动时都会带上，可以直接粘贴 .env
- 新功能：OpenCode Go 可以用 OpenCode 账号登录添加 Profile，不再需要 API key
- 新功能：安卓上能完成 agent 发起的登录：chat、奏和 station 页里有登录卡片，可以复制验证码、在浏览器里登录，gcloud、aws、az 这类也行
- 新功能：连着发的几条消息挨在一起显示，只在最后一条下面显示时间
- 改进：对话里的远程屏幕和共享调试链接显示成卡片，浏览器标签页的卡片直接显示实时画面
- 改进：上传、打开文件、网页预览不再转成 base64，大文件更快、更省内存；安卓下载大文件不再每 4 MB 停一下
- 改进：Mac 上没开「本地网络」权限时，station 列表会提示，点一下就能打开系统设置；文件夹缺权限时写明是哪个文件夹并弹出授权窗口，station 不再卡住
- 改进：远程控制时安卓和远端之间也能复制粘贴图片
- 修复：station 加入其他 workspace 后，在那边也能管理 Profile、更新、刷新额度，Profile 默认同时用于这些 workspace
- 修复：station 更新重启后的几分钟里，别的 station 给它派任务被误拒
- 修复：开启安全模式后，被拒绝的设备不再反复请求信任，过期和重复的请求不再堆积
- 修复：远程控制 Mac 时显示器休眠后画面全黑；app 被关掉后重新打开远程屏幕有时只能看不能控
- 修复：共享调试打开后要转很久才连上、刚打开时偶尔显示连接失败，系统拒绝授权时说明要开哪个开关
- 修复：手机和 station 在同一局域网时请求偶尔卡住几秒；station 换线路时不再闪「正在重连」
- 修复：DeepSeek Harness 用 OpenCode Go 等线路的模型时每轮报「does not support reasoning effort」
- 修复：新对话发出第一条后顶栏标题闪成「（暂无消息）」；聊天里图片缩略图还没加载出来时点不开；HTML 预览里点过页面后 Esc 关不掉
- 修复：桌面端预览图片、视频和屏幕时鼠标移到顶栏上顶栏会消失；视频往回拖进度条时卡顿
- 修复：Mac 上同时装了测试版 youdid.wtf 和正式版时被系统当成同一个程序，「本地网络」权限打不开
- 修复：对话里几段动效同时发生时叠在一起，现在一个接一个播放
