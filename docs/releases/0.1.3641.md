- 新功能：Grok Build 可以作为 agent 的运行时，用 SuperGrok 订阅或 xAI 的 API key
- 新功能：设置 › 归档：查看和修改每台 station 的自动归档，可以只归档模型判断为做完了的 chat；「提示归档」可选不提示、做完就提示或按模型判断；「不再提醒归档」改名为「保留」，侧栏右键可以取消
- 新功能：设置里可以注销账号（只删你自己的 workspace，station 上的聊天记录和文件不受影响）、关闭「发送使用统计和错误报告」；关于里有服务条款和隐私政策
- 新功能：对话里的出错提示可以直接上报给 still.fail 团队
- 新功能：侧栏会话右键菜单和执行历史「详情」里可以复制 agent 的 session 文件路径
- 改进：批准新设备改成在受信任设备上显示安全码、在新设备上输入，两台设备直连完成；在任何 workspace 都会弹出批准框并写明是哪个 workspace，多个申请可以一次批准
- 改进：对话的运行时（如 DeepSeek Harness）没装时，发消息后说明原因，可以在对话里一键安装，装好自动继续
- 改进：电脑上的 Station 页分成概览、设置、软件与设备三页
- 改进：agent 工作时的转圈改成逐格走动，app 在后台时不再每 2 秒测一次各 station 的连接，手机更省电
- 改进：搜索结果里命中的词加上手绘风下划线，手机上不再被截掉
- 修复：安卓用一段时间后内存暴涨、被系统杀掉闪退
- 修复：多个账号时会话分摊到各账号，不再集中打满一个号的额度；额度用完又没有其他账号时提示不再刷屏，恢复后自动继续；新加的账号也能读到共享的记忆和 skill
- 修复：桌面端和安卓用邮箱验证码登录后跳不回 app
- 修复：Windows 上 still.fail 更新后，正在进行的会话被打断或出现两个 agent 同时回复
- 修复：批准新设备时偶尔提示「请求过多」、因某台 station 离线等很久；获批后 station 还没收到批准也能直接连上
- 修复：几个目录同时同步到其他 station 时，设备连不上这台 station；改了 station 的环境变量后 Codex 还用旧的
- 修复：agent 启动失败时，station 每次重启都在对话里重复发同一条报错；执行历史里较长的 station 通知显示成原始标签
- 修复：安卓对话里几段动效同时发生时叠在一起；安卓视频预览在白色画面上看不清进度条；手机上添加 Profile 时返回按钮和标题叠在一起
