- 新功能：Devin 可以作为 agent 的运行时，用 Devin 账号登录；模型列表每个系列一项，不再列出几百个组合
- 新功能：可以添加 Kimi Code Profile，用 Kimi 账号登录或填写会员 key
- 新功能：外观里可以分别设置界面、正文（消息和输入框）和代码的字体，带预览
- 新功能：密钥库在 workspace 里每台 station 上都能用，不再只限建库的那台（各台 station 和 app 都要更新到这一版）
- 改进：agent 申请使用密钥的消息改成一张卡片，条目、方式、理由和命令一目了然，批准或拒绝后卡片上显示结果
- 改进：「密钥」页的解锁状态和「锁定」移到顶部卡片；详情页点一次「显示」就能看到内容
- 改进：开启安全模式前就在用的其他设备，可以在「设置 › 安全」页输入安全码设为受信任设备，不用回工作区首页
- 改进：station 繁忙时自动排队其他 station 发来的任务，不再长时间没有回应；内存将耗尽时才停掉占用最大的任务
- 改进：添加 Profile 后进入「选择模型」步骤，可以跳过；用账号登录的 Kimi Code、OpenCode Go 在 Profile 列表里归到各自的订阅
- 改进：做完的 chat 最后一条消息下面不再显示「保留 / 归档此对话」
- 修复：打开安全模式或设备刚被确认后，「密钥」页仍说「这台设备没有在安全模式中确认」，要重启 app 才好
- 修复：输入框切换 station 后贴的图消失或变成旧图片；有 @ 引用时再添加附件，引用文字和缩略图叠在一起
- 修复：在后台收到的消息里，mermaid 图有时只显示成一个小方块；关掉的 app 预览切到别的聊天后又冒出来
- 修复：同一台 station 上两个配置登录同一个账号时，「已登录于」把这台 station 列两次
- 修复：在 station 上安装、更新 Devin 后显示「更新失败」和一屏进度条
- 修复：Node 24.22.1 安全更新；桌面端记录崩溃转储和异常退出，方便排查突然退出
- 修复：网页版本机数据损坏后每次打开都要等很久
