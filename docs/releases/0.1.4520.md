- 新功能：对话可以接力到 Slack 频道或飞书/Lark 群，也可以粘贴 Slack 消息链接接到那个 thread；入口在标题栏、⌘K、侧栏右键菜单和手机上对话的「…」，agent 会在那边发摘要接着做，原来的对话照常可用
- 新功能：agent 卡片里点「上下文」用量就能压缩上下文或清空重开，用量高时会提示压缩；Slack 和飞书里发 -compact、-clear
- 新功能：网页消息支持行内和独立数学公式
- 新功能：Windows 上的 station 也能远程查看和操控本机桌面
- 改进：网络不稳时，网恢复后几秒内就重新连上 station（之前最多要等 1 分钟，断网久了要等 10 分钟或手动重试），重连不再每次把 station 整个重读一遍
- 改进：因为连不上 station 没发出去的消息，连上后自动按顺序补发；写新对话时断网可以继续写，发送后连上时自动发出
- 改进：其他对话的 agent 发来的消息折成一行，写明谁发给谁，不再淹没对话，也不再算未读
- 改进：输入框里上传失败的附件可以点重试；安卓上附件还在上传时也能直接发送，等附件传完再发出；同一个文件再次上传时，station 已经有就直接复用
- 改进：agent 申请密钥后批准就直接收到授权，不用再回一句「已批准」；agent 用密钥跑的命令还没结束时，station 不会自动更新
- 改进：代码块的配色网页、桌面和手机一致
- 修复：没有 npm 的机器上无法在 station 页安装 Codex、DeepSeek Harness、Grok Build 和 Cursor，也不显示原因
- 修复：安卓 ＋ 里的「照片」和最近照片条选不了视频
- 修复：station 重启后，设置「密钥」里的旧申请显示成可批准，点了只会报错，现在显示为已过期
- 修复：屏幕助手退出后，station 偶尔多启动一次助手、多弹一次授权窗口
