- 新功能：安卓正式版换成新版 app（mbui），从 0.1.4520 原地升级，登录和聊天保留
- 新功能：聊天里的图片可以引用回复：电脑上把鼠标移到图片上点「引用」，手机网页长按图片，图片不会重新上传
- 新功能：station 页的浏览器标签页可以直接关闭，能看到并打开是哪个对话开的它；对话归档时它开的标签页一起关掉
- 新功能：远程控制顶栏常驻，不再挡住远程窗口的标题栏，可以在新窗口中打开；控制面板可选画质（自动/流畅/高清/原画）、编码（自动用 H.265 或只用 H.264）、发送组合键、全屏，控制 Windows 时可以调被控电脑的显示缩放（断开后恢复）；连接统计显示线路、延迟、丢包、帧率、码率、编解码方式，可以复制诊断
- 改进：远程控制在远距离和丢包的网络下更流畅：帧率不受延迟限制，带宽不够时先降码率保帧率、很低时降到 720p；刚连上时不再卡顿；只显示一个鼠标指针，大小随画面缩放；解码器压帧时自动改用 H.264
- 改进：agent 之间的往来不再出现在对话里（也不再发到 Slack/飞书），在对话的「…」里点「agent 往来」按对方对话查看；网页对话右上角只留「…」和侧栏开关，文件、接力等收进「…」
- 改进：设置分成带图标的小卡片，workspace 单独一张卡片，「关于」里有版本、更新日志和条款
- 改进：用量页的每日柱状图重做：选中那天的金额放在图上方，按人分段，多人时列出每人当天花了多少
- 改进：公式支持 TeX 括号，由客户端 core 统一排版；金额和 shell 变量不再被误识别成公式
- 改进：安全模式等待批准时也能切换 workspace、打开设置；加入另一个开了安全模式的 workspace 的 station 不再一直显示离线，被拦下时直接说原因和怎么办；受信任设备拒绝过一次后，同一台新设备再请求也会再弹出
- 改进：账号和成员头像存在本机，没网或连不上 Google 时也显示上次的头像
- 改进：agent 工作中那一行每轮都平滑出现，不再突然弹出让消息跳动
- 修复：聊天分页被隐藏消息卡住，长列表滚到边缘后不继续加载
- 修复：桌面端远程控制屏幕时，鼠标移到顶部后常常拖不动窗口；文件或远程屏幕上方的栏挡住名字下面那一行
- 修复：手机网页上「已归档」这类提示盖住底栏中间的按钮；对话顶栏和会话列表顶栏高度不一致
