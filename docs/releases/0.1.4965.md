- 新功能：视频和歌换成同一个播放器：暂停时可以逐帧前后（网页上 Shift 一次 10 帧），时间精确到毫秒，显示第几帧 / 共几帧和帧率；拖进度条时画面逐帧跟手；倍速 0.1× 到 2×；可以存下当前这一帧；播完倒数 5 秒自动播下一集；手机浏览器里双击快退快进 15 秒、长按 2 倍速
- 新功能：聊天和网盘里的文件下载，关掉预览、离开页面、关掉 app 都会接着下，连不上 station 时等连上再下；进度显示在文件卡片和「传输」里，可以取消、重试
- 新功能：agent 可以申请把用到的密码、token 存进密钥库，在卡片上批准后才存入；申请使用密钥时可以指定在另一台 station 上运行；申请卡片更简洁：一个「允许」按钮，时长在旁边选
- 新功能：station 页新增「进程」：按对话列出 still.fail 和 agent 跑的程序占用的 CPU、内存、网络和磁盘，可以结束对话留下的进程；station 概览和 agent 头像卡片里直接显示占用
- 新功能：iOS 模拟器屏幕有了主屏、多任务、锁屏、软键盘和截图按钮；消息里的屏幕卡片可以在对话侧边打开，边聊边看
- 新功能：安卓平板和折叠屏按屏幕大小换布局：大屏三栏，中屏侧栏和页面是并排的两块面板；长按弹出菜单，原来要悬停才出现的按钮在触屏上一直显示
- 改进：Claude agent 每次开始对话时载入的内容减少约三分之一，更省用量
- 改进：agent 开始干活时各设备不再重新连 station；离线时漏掉的 agent 步骤在后台自己补齐；最近用过的 agent 执行历史存进本机，往回翻不用等
- 改进：有对话在干活时，侧栏的转圈和等待动画只在变化时才绘制，CPU 占用明显降低
- 改进：消息里的表格放不下时左右滑动，不再挤成很窄的几列；自己发的图片直接用本机的，不再从 station 拉回来
- 改进：安装包变小；上传时选「保留两者」，新文件命名为「名字 2.txt」
- 改进：安卓上网不好时看视频，下到一点就先播，显示下载速度，拖动和重开不再重下已下过的部分；图片和视频放大后拖动有惯性
- 改进：安卓上的设置各页（账号、安全、Workspace、用量、记忆、文件、Profile 等）和网页手机版一致
- 修复：打开旧聊天时有记录却显示空白，加载历史失败后可以点「重试」
- 修复：账号换了目录或被移除后，执行历史缺了之前的记录，正在运行的对话底部一直堆着「思考中」
- 修复：执行历史里点 Slack 用户名选「这是我」反而解除了绑定
- 修复：手机网页第一次从相册选图可能没加进消息；选中文字后高亮不显示、选区把手乱跳；滑到顶部或底部后消息反复抖动；长按首页会话误选整页文字
