- 新功能：登录 Anthropic、OpenAI 等账号，以及 agent 发起的命令行登录（gcloud、az 等），可以在 station 自己的浏览器里完成，在 app 里看着那个标签页操作；Claude 账号这样登录不用再贴授权码
- 新功能：可以用 Hermes Agent 处理对话，能读出已配置的模型，也可以按名称添加
- 新功能：选账号时「自动」旁边多了「重新分配」，点一下就按各账号剩余的额度重新挑一个账号
- 新功能：安卓上 Station 页多了「进程」，按对话看 still.fail 用了多少 CPU、内存和网络，可以结束对话起的进程；概览里可以直接进这台 station 的记忆和 ADB 共享
- 改进：station 不再时常卡住：以前 agent 干活时每隔几分钟会卡住半分钟到一分钟，各设备显示断开；对话多、对话长或内存紧的机器上，打开对话列表、发消息、断线重连都快了很多；station 更新后各设备几秒内连回来，不再从头读取全部对话
- 改进：station 所在电脑的磁盘快满时，提前清理已归档对话的工作目录（聊天里发过的文件保留），不再让磁盘被撑满
- 改进：接力到 Slack 频道或飞书群时，agent 的摘要直接接在开场那条消息里，不用点开 thread 就能看到在聊什么
- 改进：同一台机器上几个任务都要截图、开窗口时，只在真正用到屏幕的那一会儿排队，编译和测试照常一起跑
- 改进：网页上快速滚动、长代码、长会话列表更流畅；会变的数字（进度、计时）宽度不再跳；⌘K 搜索框显示快捷键和操作提示；各处悬停底色统一
- 改进：安卓上各页和网页、电脑上的是同一页：密钥、连接、Station、文件、公开分享、分享给其他 workspace、接力到频道；聊天换成同一个输入框，点 Station 文件的卡片可以选按路径还是按文件发送；设置整理成一份目录，各种屏幕上分组和顺序一样，每行写着现在的状态，要处理的标红
- 改进：安卓上第一次打开长对话、切换对话更快，不再先显示加载；滚动会话列表和聊天不再隔一段卡一下；有 agent 在干活时首页不再一直重画，更省电
- 改进：安卓界面圆角统一、贴角的按钮和外框同心；滚动条重新设计，更细、可以拖；分割线去掉，改用间距分开；输入框内容多时可以上下滚动查看
- 改进：安卓平板分几栏只看屏幕宽度，侧栏和页面底色分开；接上鼠标或触控板时样子不再跟着变；分屏布局下按住露出的面板左右拖就能拉出来；手机只竖着用（全屏看视频、看远程屏幕时仍可横过来）
- 修复：agent 之间互相转达、开新对话时改用英文，连带回你的话也变成英文；现在都按你用的语言写
- 修复：agent 在消息里用相对路径链接工作目录里的文件时，发出来的链接点开提示「无法打开」；现在文件照样作为附件发出
- 修复：额度用完时，明明还有别的账号有额度，对话却说「没有其他可用账号」，一直等到额度恢复
- 修复：晚上经 Cloudflare 中继的连接会被断开、之后一直连不上，中继也会提前停止接受新连接；从家里带出去的设备不会一直停在变慢的中继线路上
- 修复：安全模式下批准新设备时，关掉显示安全码的弹窗后码就失效，新设备输对了也提示「错误次数过多」；现在未获批准时说明原因（被拒绝、安全码过期、连不上显示安全码的设备）
- 修复：发出的消息要等从 station 传回来才显示已发出，连发几条后一条要等前一条；新对话发出第一条后一直看不到 agent 正在做什么；还没起名的对话标题来回变，现在显示「新对话」；停下来的 agent 卡片不显示费用和上下文，也找不到压缩、清空上下文
- 修复：长对话加载到一半停住，现在可以重试；手机发的截图和照片发送中和发完大小不一样、长截图变成很窄的一条；竖着录的视频被裁成横的；station 连不上时打开没看过的文件夹一直转圈，现在写出原因，连上后自动重新读取
- 修复：手机网页上列表滑到顶部或底部时抖动；奏页的回复框被底部导航栏遮住；浏览器返回首页后下方栏消失；做完的对话行首多出「归档」按钮（左滑或长按仍可归档）
- 修复：安卓输入框接外接键盘时按词移动、到行首行尾、删词、Ctrl+A/C/X/Z 不起作用，双击选不中词；回车把引用说明、图片上写的字清掉；图片还没上传完就发送偶尔发出两张、先显示成普通附件；＋ 里的「Station 文件」点了没反应
- 修复：安卓上打开、关闭图片和视频预览时闪一下，关闭时飞回的位置不对；磨砂玻璃上一圈圈色带；列表拉到边缘回弹时闪出白色条纹；拖视频进度条时按钮来回闪；看视频拖动或关掉后后台还在下载、抢网速；点「允许」用密钥时直接报错，不弹指纹或锁屏验证
