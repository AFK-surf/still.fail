- 新功能：Mac 和 Windows 版换成新做的 app，和安卓是同一套界面：装着旧版的点「更新」就换过来，登录、对话和设置都在，这台电脑上跑着的 station 也接着跑；「添加 station」里可以直接添加这台电脑；「检查更新」直接弹窗说结果，列出这次更新带来的改动；Mac 屏幕右边缘显示待处理对话的浮窗去掉了
- 新功能：新的品牌形象：标志换成 s. 和一个橙点，应用图标、启动画面、网页图标和官网都跟着换
- 新功能：对话信息里的「公开分享」换成「分享图片」：整段对话画成一张海报，电脑上复制、手机上保存到相册
- 新功能：agent 需要只有你拿得到的密钥（比如要登录控制台才能新建的 API key）时，会在对话里发一张卡片请你直接填进去，存进密钥库，agent 看不到原值
- 新功能：带图片或文件的消息上传时显示「正在上传 42%」；安卓上 ＋ 里的最近照片和视频可以多选；全屏预览里右键或长按图片可以复制
- 改进：密钥页重新排过：待批准的申请在最上面；具体的密钥收进「全部密钥」一张列表，可以按名称、域名、变量名搜索，每条写明 agent 怎么拿到它、最近在哪个对话里用过；可以删除自己的库
- 改进：设置重新整理：大屏旁边的目录和小屏的设置页是同一份，每组设置放在一张卡片里，每行写着现在的状态，有问题的标红；Profile 显示「N 个需查看」时，点进去能看到是哪个、为什么
- 改进：对话里显示的用量和「用量」页是同一份数，agent 干活时几秒内就跟上，子 agent 的调用也算在内；用量图按住横着拖可以一天天看
- 改进：固定的对话不再提示归档，也不会被自动归档；做完了的对话都能左滑归档，有未读的、固定的也可以
- 改进：待处理只列还没看过的，读过的对话、看过的 station 状况不再一直留在里面
- 改进：重开 app 后，进有新消息的对话立刻显示已有的消息；station 卡片上的数字、登录列表、任务输出、进程、记忆页直接显示上次的内容，不再先转圈
- 改进：输入框里 @ 引用对话时，也能找到同一个工作区里别的 station 上的对话；消息里的对话引用显示成对话名，点一下打开
- 改进：灰色小字、链接、图标和代码高亮在各种底色上都更清楚了（按无障碍标准调过）
- 改进：消息里的视频在缩略图上显示时长，打开后立即显示分辨率、时长和帧率；图片预览显示分辨率
- 改进：正式版的更新日志不再分端，一次发布一条
- 改进：agent 不再把公式放进代码块；在 Slack、飞书里写公式改用看得懂的符号，不再贴 TeX 源码
- 改进：安卓上滑动长对话、首页、文件夹和任务输出更流畅、更省电，打开对话、补消息更快；中屏（折叠屏展开、平板竖着用）上没在用的面板只露出窄窄一条，点开的页面滑进来，返回手势跟着手指走
- 修复：账号的 Claude 登录过期又续不上时，账号页仍显示「已登录」，对话还会派到这个号上停在「认证失败」；现在显示需要重新登录，对话自动换到别的账号接着做
- 修复：station 重启时开着的 Codex 对话丢掉 station 的工具；新版 Hermes 新账号第一次启动失败、读不出模型列表，也用不上账号里指定的已有配置和记忆
- 修复：对话说了在等待、随后这一轮出错时，列表一直显示等待中；station 意外重启后，等待中的对话到时间不再继续；agent 早已开始干别的，进度还一直显示「加载工具」
- 修复：agent 之间来往很多的对话，打开后消息不停闪烁、只剩转圈；对话记录里收起的一行露出 **、## 这类标记
