- 新功能：对话信息（「…」）里新增「图片、文件和链接」：对话里发过的图片、视频、文件、链接和 PR 按类浏览、筛选，图片和视频按天、按发它们的那条消息分组，点「在对话中查看」跳回那条消息；对话信息里直接列出最新的几个 PR，按状态上色
- 新功能：和 station 在同一个 Tailscale 网络时直接经 Tailscale 连接；workspace 设置里的「连接方式」可以关掉某个中继或某种直连方式；连过的 station 下次直接按记住的地址连，中继连不上也能连上
- 新功能：Station 右上角菜单可以远程「重启 station」，进行中的对话不中断；高级网络设置新增「中继走 UDP」，保存后立即生效
- 新功能：Windows station 可以切换「以管理员身份运行」，远程时没人确认 UAC 会自动取消，station 不会失联
- 新功能：通知设置里可以单独关掉某个 workspace 的通知；不在当前 workspace 的通知也会提醒，标题前带 workspace 名；安卓在 app 没打开时也能收到通知
- 新功能：agent 要用你的安卓手机调试时会在对话里申请，允许后只有那个对话能用，可以在「共享调试」里随时收回
- 新功能：密钥库可以存文件（kubeconfig、服务账号密钥、证书等），agent 用时临时写成文件给命令
- 新功能：远程看屏幕能听到 Mac、Windows 电脑播放的声音；可以选帧率（最高 120）；控制时按键行多了鼠标左右键和 F1–F12、Del、Home 等常用键；控制 Windows 时可以临时切分辨率，退出后改回
- 新功能：Mac、Windows 上可以前进了（⌘] 或 Ctrl+]、鼠标前进键），大屏上切换对话后后退回到之前看过的对话；Mac 上可以把别的应用的文字拖进输入框
- 新功能：鼠标指着 agent 头像出来的卡片上，名字、最近几步、上下文、账号、后台都能点进去；卡片里一行显示后台在跑的子 agent、命令数和清单进度
- 新功能：消息名字行右侧可以复制这条消息的链接、分享这一轮的图片（安卓上长按消息后在弹出条里）
- 新功能：Slack 线程里 agent 做完或要你处理时，最后一条消息下面有一行灰字说明状态；在 Slack 线程里说过话的对话也出现在「我参与的」里
- 改进：station 默认把去掉个人信息后的运行日志发给 still.fail，用来排查连接和同步问题；station 设置的「诊断」里可以关掉
- 改进：品牌标志换回呆萌的脸：浅色界面黑脸、深色界面白脸；应用图标、网页图标、插图都跟着换
- 改进：远程看屏幕更清楚、更省电：局域网下码率更高，静止画面更清晰，「自动」画质按窗口实际像素要画面；安卓、Mac、Windows 上画面交给系统解码直接显示，不再发烫；颜色不再发淡
- 改进：station 之间传文件（远程任务的文件、对话附件、目录同步、网盘复制）快了很多，离得越远越明显
- 改进：分享图片显示最近 7 天各类账号用了多少 token、值多少钱；每条消息的勾选框排在左边一列，附件可以移出再放回
- 改进：动效统一：切换页面、侧栏、看图、搜索弹出、输入框长高从静止平稳起步、稳稳停住，更利落；点完选项、忽略、批准密钥后卡片在原处换成结果，不再挪动消息列表
- 改进：消息里的可视化网页跟随外观里设置的字体，没画好时显示占位，画好后从上往下刷入，切回最近的对话直接显示；执行历史的命令和输出用等宽字体；Windows 上文字改用 ClearType，和系统其他应用一样清晰
- 修复：网络换线或某个中继断了时，跟 station 的连接不再断开；离得很远、来回要好几秒的 station 不再一直连不上；网不好时视频卡在「等待连接 station」
- 修复：station 更新期间显示「正在更新」并带动着的图标，不再只显示「离线」
- 修复：agent 卡在一个问题上时，每次被后台任务叫醒都再推一遍「需要你处理」；现在同一个问题只提醒一次
- 修复：安全模式下没有受信任身份的设备批准新设备后，station 一直拒绝之后获批的设备；station 的安全模式记录和 workspace 不一致时明确提示要重置
- 修复：新对话里选好的 station 离线时不再自动换到另一台，而是留在你选的那台并提示连不上；换新上下文后再打开对话又提示「缓存已过期」
- 修复：agent 操作 station 的浏览器时不再把它拉到前台、打断正在用那台电脑的人；消息里指向文件夹或省略了几级的路径误报「文件不存在」
- 修复：app 有时一打开就显示「核心崩溃」；安卓上按系统返回有时直接退出 app；安卓打开 app 时对话列表出来得更快

- 修复：菜单、弹窗、⌘K 淡入淡出时透出下面的字；关闭图片、视频预览时最后闪一下；Windows、Mac 上新建对话页顶栏拖不动窗口；连着 Slack、飞书的对话里「抄送」来回乱跳
