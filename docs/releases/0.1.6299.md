- 新功能：安卓设置里新增共享调试总开关（设置 › 共享调试），默认关；打开后一直保持，手机重启、app 在后台或被清掉、更新后都会自己恢复共享，不用再手动打开 app 或无线调试
- 新功能：调试手机的申请卡显示这台 station 是否真的连上了手机，还没配对时整张卡点一下去配对；手机没开开发者选项或无线调试时，卡片先说缺什么
- 新功能：设置里可以打开「性能记录」，把 CPU、各线程占用、发热等级和帧数记在本机，方便排查发烫
- 改进：去掉了「奏」页面：等你决定的卡片在对话里直接回答，新的出现在待处理里；agent 申请用密钥、存密钥、借手机时不再干等你批准，期间可以照常跟它说别的
- 改进：存在密钥库里的登录项，agent 用的时候连账号一起拿到，不用再在聊天里问一次；station 更新或重启后，已经批准过的密钥授权不用再批准一次
- 改进：模型暂时满载时不再误报「额度用完」、把账号当成用完去换号，改为隔一段时间自动重试，点停止可取消
- 改进：对话信息重新排成「对话本身和 agent」「里面有什么」「能拿它做什么」三组；agent 悬停卡片顶部把模型和账号额度合成一块，点它切换模型
- 改进：选模型的浮窗重新设计：模型是列表，思考深度一条可直接点的档位，运行时和速度点开再选；整个 app 的按钮、输入框、列表行统一成一个高度
- 改进：消息里的表格不再放在卡片里，直接排在消息中；附件改成小胶囊，带按类型区分的图标；卡片统一圆角；Mac、Windows 上悬停消息时名字行末尾是一个「⋯」菜单
- 改进：动效按要走多远定时长，近的更快、远的不猛窜，被打断时接着当时的速度走；消息列表里东西变高、变矮、进来、离开都一起平滑过去，往上翻着看时正在看的内容不动；对话列表换位置时滑过去
- 改进：能左右滑的代码块、宽表格和输入框，还有内容的一边渐隐；按钮换字时宽度平滑过渡
- 改进：本机缓存页先显示总量和各类占用，对话用本来的名字、按占用从大到小排
- 改进：分享图片按账号类别列出每个模型的 token 和花费
- 改进：去掉了上一版加的「中继走 UDP」开关，station 和中继之间统一走原来的方式
- 修复：点进对话老要加载：本机缓存被越涨越大的搜索索引占满、把消息挤掉了；现在消息一直留在本机，以前被清掉的会自动同步回来，多占的空间还给设备
- 修复：Mac 上 Spotlight 因 still.fail 反复重搜长时间占满 CPU（旧版留下的也会清掉）；Windows 上不再反复扫盘；看过的执行历史、日志、文件夹关掉后不再在后台占着资源
- 修复：一条中继变慢或拥堵时连接还一直走它，几秒的来回、几十 KB/s 的下载；手机网络很慢时一直「正在重新连接」；弱网恢复后发送卡在旧连接上要重开 app；网络恢复后马上打开的页面报「无响应」
- 修复：Cloudflare 中继误以为当天额度用完而整天拒绝连接；网络差时经北京中继下载附件卡十几秒；每天第一次连 station 更快
- 修复：远程桌面在局域网下被压到很低的码率和 720p、拖动卡顿；「在新窗口打开」要等十几秒；控制中心等面板上的点击穿透到远程画面
- 修复：按停止后 agent 被自己在后台开着的命令叫醒、马上又开始干活；station 更新时已经说了「做完」的 agent 被标成「意外停止」；有监控在跑时 agent 在等的别的事被「监控中」盖住
- 修复：安卓在输入框里直接拍照，上传的是约 200 像素宽的小预览图，现在上传原图；输入框里待发的宽图、长图预览糊成一片
- 修复：消息里单独一行的文件链接，下一行紧跟文字时变成普通链接；点引用跳过去时只高亮被引用的那段字
- 修复：发出去的消息往上飞时被输入框、「处理中」盖住；输入框换行时最后两行闪一下；滚到最下面时归档对话列表整个跳一下；执行历史往上翻到顶会一直加载到最开头
- 修复：新设备配对时安全码过期或被拒绝会立刻提示并可重新获取，安全码显示有效时间
- 修复：Mac 上网页预览滑到输入框下面时输入框变成一片灰；窗口右上角的按钮贴着圆角；选模型浮窗里选项多时下面的模型被空白挡住；拖侧栏宽度时中途弹出资料卡
