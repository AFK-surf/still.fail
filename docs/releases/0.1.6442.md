- 新功能：station 的浏览器改成不开窗口的 Chrome，每个对话有自己隔开的浏览器环境；登录状态存进密钥库，按网站、对话和时长授权给对话使用
- 改进：缓存过期提示里可以选下次启动时「接着聊」还是「换新上下文」，每个对话随时可改，被消息或通知叫醒时也照这个选择；station 设置里的「缓存过期后自动换新上下文」作为默认值
- 改进：agent 之间的往来不再写进对话记录，打开对话看到的就是对话本身的消息，往来在对话的「agent 往来」里单独看
- 改进：安卓的共享调试只需在手机上配对一次，之后借给哪台 station 都不用再配对；station 重启不再让手机重新弹出「已连接到无线调试」
- 改进：新版本在后台自己下载，安卓离开 app 一段时间后、Mac 和 Windows 退出时自动装好；手动更新时从检查到下载是一条连着的进度，下好后显示「重启以更新」；安卓更新不再每次弹系统确认框，第一次允许安装后回到 app 自动接着更新
- 改进：设置里的账号列表显示登录的邮箱和哪些 station 能用，额度写成「本周剩余 78%」这样的字，小屏上也不再被截成「…」；station 的内存、磁盘写成「内存剩 12.3 G」
- 改进：记忆里分享出去的 skill 显示哪些 station 在用，哪台没同步上、为什么没同步上也写出来
- 改进：登录页、还没有 workspace、收到邀请这几页统一成 app 的样子，支持深色模式，换页时插图不再跳；在浏览器里登录时 app 提示「在浏览器中完成登录」，可以重新打开登录页；登录失败时说明原因
- 改进：进对话更快：准备消息的时间少了一半左右；消息已在本机的对话直接带着消息滑进来，只有还要从 station 读的才显示骨架；带对话链接、密钥库卡片的对话和很久以前的对话，打开不再要等半秒到一秒多；有好几台 station 时不再每隔一两秒卡一下
- 改进：新对话发第一条消息时，一按发送消息就飞进对话、原来的画面同时淡出，不再停在输入框里等对话建好
- 改进：远程屏幕因那台 Mac 缺授权打不开时，可以直接点「前往权限设置」
- 改进：Station 的文件面板合成一整块，列表后面没有深一块的底，行和标题对齐，文件夹带箭头
- 改进：选模型时「思考深度」换档，滑块滑到新档位，不再原地淡出淡入；小屏上的按钮跟大屏一样高，卡片底角的按钮不再挤在边上；播放器的「无法播放」「播放结束」改成居中的卡片，缓冲提示的宽度不再随网速跳动
- 修复：连接正常时偶尔改走较慢的中继；连海外 station 时没有试经北京转发的线路；开着 VPN 时在 Wi‑Fi、有线、蜂窝之间切换后 app 不知道网络变了；部分 Mac 虚拟机上视频和附件传得慢
- 修复：安卓上视频播着时切到别的 app 待几分钟，回来显示「无法播放」；视频播放失败的提示后面是空的；安卓上快速下拉视频有时关不掉；上传中发出的视频中途变成文件卡片
- 修复：点开对话里的图片时缩略图先空一下；图片加载时占位先变模糊一下；视频展开、收起时播放图标、名字条和控制条一下子出现或消失
- 修复：图片标注里拖选中框的四个角能改大小了（之前会把整个框挪走），文字拖右下角能缩放；点一下选中标注不再多记一步撤销
- 修复：最近全是 agent 之间往来的对话，打开后一直转圈、看不到之前的消息
- 修复：消息没占满一屏的对话，往上滚时消息在顶部和输入框之间来回跳；对话列表里一个对话往下挪时，别的对话跟着闪一下
- 修复：执行记录里中文界面显示英文 Thinking；想完的思考一行行堆成「正在思考…」；能点开的行、Station 进程表的行太矮不好点
- 修复：对话末尾提醒里的「忽略」不好点：现在点按范围更大，按下有底色，提醒折成多行时它留在第一行行尾
- 修复：安卓上在页面之间用系统返回，有时直接退到后台
- 修复：名字是中文的 skill 分享后别的 station 一直收不到；分享的 skill 改名后跟着新名字走，删掉后不再分享；名字带 Windows 不认的字符时，Windows 上的 station 停掉其余分享；远程任务名字是中文时取回的文件和别的任务混在一起
- 修复：Slack 里刚好在上一轮结束时发的消息，线程里先显示「已完成」却没有工作状态
