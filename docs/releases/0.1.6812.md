- 新功能：选模型浮窗分成两级：先列常用和喜欢的模型，「全部模型」里按厂商和系列分组（带各家标志）查看全部、勾选喜欢；深度和速度紧跟在模型名后面，中屏、大屏的思考深度单独一列，运行时和速度挪到底部和账号并排；不再有「默认」「跟随订阅」，直接显示实际的档位和速度；小屏放不下时可以滚动
- 新功能：Profile 不再需要勾选启用模型，查到的模型都能用，以前勾选过的自动算作喜欢；Profile 显示订阅账号的档位（如 Ultra、Pro 200），账号额度写出重置卡的到期时间；同一个 OpenCode Go 账号登在多台 station 上只显示一行
- 新功能：用量页重新设计：顶部是累计 token、归档的对话、跨设备任务、决策点击率和一起干活的设备，接着是近一年的 token 活跃格子图（悬停看那天的日期和用量）、各设备的工作量和对话来源，下面是按人或按模型分段的每日费用和最花钱的对话
- 新功能：密钥授权可以设闲置或固定到期时间，到期自动失效；已经处理过的卡片可以再点开看申请详情
- 新功能：模拟器页面可以看日志、重启 App、改外观和文字大小、截图；Xcode 27 的模拟器可以直接用电脑键盘打字
- 新功能：对话里的文件可以右键或长按下载，卡片上显示下载进度；Mac 和 Windows 上右键消息或点它的「⋯」可以「复制消息」，连 Markdown 原文一起复制，菜单开着时这条消息整行高亮
- 新功能：指向某条消息的链接显示成对话标题，悬停卡片显示那条消息的发送者、时间和内容
- 改进：对话页右上角拆成两个按钮：ⓘ 只看这个对话本身（谁发起、哪些 agent、PR、图片和文件），「⋯」是和侧栏右键同一份的操作菜单；对话菜单分成三组，「归档」挪到「保留」后面，不再贴着屏幕底边
- 改进：弹窗里往里走的步骤（预设的「添加目录」「浏览文件夹」、添加连接的向导）在同一个弹窗里滑进来，返回、Esc 和返回手势先退一步，不再直接关掉、丢掉填好的内容；弹窗叠弹窗不再越叠越暗，小屏上新面板把下面那层顶上去，确认框只有内容那么高
- 改进：安全模式下，受信任设备不能再在「设置 › 安全」里点一下就批准新设备，只能在新设备上输入受信任设备显示的安全码；输入安全码时弹出数字键盘，验证成功后自动收起
- 改进：安卓上手指在下方栏上滑过、拿起选择、点另一格、拉开或收起其他栏时轻震，忽略卡片、置顶对话、清空上下文、重试消息等操作也会轻震；下方栏可以放「密钥」（默认在第二栏第 4 格），「已归档」移到第二栏最左边，上滑打开其他栏时整栏让开手指
- 改进：切回 app 时就检查新版本（至少隔 5 分钟，原来是一小时）；大屏侧栏下载更新时显示进度，下好后的「重启更新」键用向上箭头，悬停时每个阶段都有提示
- 改进：出错时不再显示原始的系统或网络报错，改说是哪类问题、什么时候发生的；agent 这一轮失败时用一句话说清出了什么错，点提示能看到并复制原始报错
- 改进：文件页合并收藏入口，列表显示文件大小和修改时间；推荐归档的对话和别的对话按时间混排；小屏首页的筛选和 workspace 换了位置，文件、用量、Station 等页面的设置键挪到右上角；网页版打开直接进登录页
- 改进：agent 卡片里各行的标签对成一列；「停止当前任务」改成状态行末尾的红色圆形按钮，状态很长时不再被挤成三行；分享卡片挑样式的那一排是每种样式的缩略图，可以左右滑，分享按钮改用分享图标
- 改进：开启账号分享前说明分享机制和 Claude 的安全访问要求；分享设置写清开关、登录位置和可用范围
- 改进：station 的工作区占用过大时提醒 agent 清理或提高上限，agent 也可以请 station 清理不用的远程工作副本；加入别的 workspace 后，那边的对话只用那个 workspace 自己的记忆和 skill
- 改进：后台忙时进入对话更及时，对话名字和数据变化马上更新；断线后按批补齐消息；对话列表更新时不再卡顿；网络慢时打开图片、播放视频更快，打开过的图片再打开不重新加载；Mac 上的 station 释放的内存当场还给系统，占用更少
- 修复：station 繁忙、历史对话多或归档执行记录被反复解压时聊天和新消息长时间没响应；打开对话偶尔卡住；重启后打开部分对话卡顿；安卓上 app 在后台放久了再打开卡住；station 更新时新对话打不开，远程任务多时更新后长时间连不上；归档对话的执行记录没压缩、占用大量磁盘
- 修复：发消息后卡片已经关了，agent 还以为卡片在等；追问后仍需要的登录和授权申请可以重新出现；agent 忙着时点会静默关闭卡片的选项只报「等待状态已变化」，现在暂时不可点并说明原因；等待处理的卡片里还显示已下线的「奏」；卡片底部按钮的文字和圆角对不齐
- 修复：「添加目录」在家目录里挂着 OrbStack 等网络盘的 station 上一直是空的，预设的「添加目录」看不到扫描到的仓库；消息里提到的文件已经不在时还能打开预览
- 修复：更新时下载中发现更新的版本有时无法继续，一直操作时后台更新一直等，更新后偶尔还在跑旧版本的核心；设备列表、关于页和装好的应用还显示旧名字
- 修复：图片、文件加进输入框时被横着切开、圆角缺失，引用或附件出现时输入框没及时展开；引用里的图片和视频比卡片还圆；很扁的宽图预览太矮；截图加载时占位有横向色带；收起新对话的图片预览后缩略图变空白；引用的图片和原图预览互相干扰；比所在列窄的 Mermaid 图上下大片留白；分享对话图片时表格显示不全
- 修复：安卓上视频切到后台还一直播，现在自动暂停；Mac 上网慢时视频已经在播还挂着「缓冲中」；视频时长、文件名和部分按钮文字被意外省略成「…」
- 修复：选常用模型后面板关闭时闪一下；缓存过期时点开「接着聊 / 换新上下文」菜单往下跳；模型满载时可以在提示旁取消自动重试；用量页年度格子在月份处显示「…」，鼠标停在图表上页面滚不动
