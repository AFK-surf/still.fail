- 新功能：选模型时可以限制上下文长度（比如把 Opus 5.5 限在 500K 或 300K），在浮窗底部的「上下文」里选，每个模型记住上次选的
- 新功能：对话中途可以切换 agent 运行时，原来的执行历史照样能看
- 新功能：设置页加了搜索框，按名字找设置，点结果直接打开那一页
- 新功能：已归档的对话可以直接发消息，发了自动还原；左滑归档正在进行中的对话前先确认
- 新功能：分享卡片新增 30 种《千恋＊万花》主题样式（女主角、Q 版、游戏界面、穗织画报、合照等），样式那一排可以横着滑；每种样式单独下载并显示进度，下好之前不能保存，失败可以重试；打开分享图片直接用本机已有的对话内容生成预览，不再一直转圈
- 新功能：触控时文件预览、页面和设置页里的文字也能长按选中、拖动两端调整并复制；中屏长按选字后接着横滑或拖手柄，不再被切换卡片的手势打断
- 新功能：Station 的资源里显示每张 GPU 的空闲程度、显存和型号
- 改进：更新在侧栏和关于页都按「有新版本、正在下载、重启更新」三步显示，下好后写明从哪个版本更新到哪个版本；关于页的「检查更新」单独一行；启动时显示进度条
- 改进：网页上的「分享到 still.fail」（浏览器扩展、装到桌面的网页）改用 app 的分享面板；分享面板在大屏上是紧凑的面板、对话带时间，手机上图标放回白底方块，最后一行叫「新建对话」
- 改进：共享调试在手机上配对一次后，station 重启不再弹出无线调试连接通知；agent 用完手机可以自己交还授权，之后手机断开重连不再惊动它
- 改进：Station 里的 Profile 按账号类型分组，保留额度，可以搜索
- 改进：已处理卡片的详情改成点结果那一行打开，悬停不再弹出、不会同时出两个框；对话菜单去掉了「复制 session 文件路径」；以前的老对话卡片上只显示轮数
- 改进：侧栏和右侧栏开合时不再重建列表，动画更顺；连接页、密钥详情、设置页里几块出现或变高变矮，文件页改名、上传时，都平滑过渡；两个 agent 同时干活、一个先结束时，两行「处理中」不再一下子换位置
- 改进：Mac 上登录卡片等 1Password 时写明在等，也可以改在画面中登录；1Password 连不上时说清楚，可以再试
- 改进：写在一行的 $$…$$ 公式显示成公式，不再露出 TeX 源码；表格里带绝对值竖线的公式不再把一格拆成几格
- 修复：station 忙、内存紧、刚更新或闲置一会儿后，以及自动归档检查、清理归档对话、给别的机器同步目录、整理数据库时，会卡住几秒到几十秒：新消息和推送通知迟迟不到、图片加载不出来、发消息卡住或报 database is locked、新开对话时所有设备断开
- 修复：侧栏和对话页改由 app 自己拼，station 不再为每台设备反复重读；轮次多的对话每过一轮不再整份重读；打开归档列表不再要等一分钟；用量页统计不再每次几十秒、拖慢别的读取；长对话历史在后台补时不再占满磁盘，也不会补到一半停住
- 修复：station 更新时有时没交接好，设备断开半分钟以上、连回来还要从头同步，正在跑的 Codex 回合也可能被打断；更新后打开执行记录先卡几秒；沙箱里的任务刚启动就断线时不再重启
- 修复：没起名的对话在登录卡片、密钥库使用记录、搜索结果、转发到 Slack 的消息和执行历史里，显示成对话编号或第一条消息原文，现在和对话列表一样显示「新对话」或 agent 起的名字
- 修复：agent 停下来等你回答后，之后每一轮结束都再推一次「需要你」；停止任务后误显示出错，失败提示重复显示；用量跨工作区或跨日统计错误，缺旧记录时现在会注明
- 修复：手机在安全模式的锁里批准后拿不到密钥库的钥匙：有钥匙的设备现在自动给新设备，新设备的「密钥」页也能「申请授权」，你的其他设备会弹出申请；设备重装后「授权新设备」报错、整个库写不进新版本；后加进 workspace 的 station 发的「存入密钥库」卡片在别的设备上批不了
- 修复：共享调试卡在「正在连接 adb」，手机配对完成后仍显示未配对
- 修复：未发出的消息不能选中复制；滑动 @ 候选时菜单关掉；安卓上粘贴超长文字转成文件后输入框打不进字；以前看过的消息里屏幕和共享调试的链接重新显示成卡片；点开出错提示后字号变大；往来记录很长时可以分批加载
- 修复：Mac 上更新下载中途断过、续传下完后仍显示更新失败；鼠标停在设置里更新那一行时 app 可能崩溃；Windows app 连不上同一台电脑 WSL（镜像网络）里的 station；Mac 上正式版 station 的原生部分改用 Developer ID 签名
