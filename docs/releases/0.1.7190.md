- 新功能：Google 的 Antigravity CLI 可以作为 agent 的运行时，用 Gemini 的 API key
- 新功能：关于页可以关掉自动更新；关掉后有新版本照样提示，你点了才下载和安装
- 新功能：数据外流可以授权 `operate`：外部的 agent 能以发起请求的成员身份操作 station（开对话、发消息、答卡片等）；批准页写明了这项授权的含义
- 新功能：agent 一轮做完、对话还没有标题时，station 会提醒它起一个
- 改进：在等 CI 之类的对话，agent 进程闲着时会被放掉，到点再重新唤起，station 省下不少内存
- 改进：agent 跑远程任务带回的文件 6 小时没动过就自动清掉；agent 进程的输出日志不再无限占用硬盘
- 改进：station 只在有人看远程屏幕时才找安卓设备；对话归档时，它工作目录里留下的进程（比如 adb 服务）一起关掉；意外退出后留下的 adb 服务，下次启动时会被关掉
- 改进：网络很慢时（比如走跨洋的代理出口）station 也能连上云端，连不上时日志写出每个地址的错误
- 改进：旧记录不完整时，用量页保留可用统计并说明决策点击率无法计算；小屏首页顶栏的 workspace 名字字号调小
- 修复：station 在更新后、看工作区大小、自动归档、查登录状态、对话或阅读记录很多时会卡住几秒到几十秒，用量页、后台任务列表、对话列表和搜索都比以前快
- 修复：数据外流在本机读取时漏掉 app 里开的对话和它们的用量
- 修复：station 连不上 still.fail cloud 时，不再拒绝同一 workspace 的其他 station，共享的账号照常同步；Profile 页写明是哪台 station 连不上，不再一直显示「等待同步」
- 修复：安装包缺少后台程序，导致工作区恢复、对话导出或登录保存无法完成；部分情况下对话首条消息显示错误或新消息写入失败
- 修复：界面某一块出错时整个 app 闪退，现在只把那一块换成「这部分显示出错了」；agent 把同一个登录发了两次的对话，在安卓上一打开就闪退
- 修复：更新后侧栏里的对话名有时全部显示成「新对话」；Codex 对话偶尔一轮下来没有 still.fail 的工具；消息交给 agent 后「等待 agent 接收」的提示多挂几秒
- 修复：station 离线时，它的设置页不再显示改不了的设置，改为提示连上后再改
- 修复：输入框长高时发送、发出后马上打字、发送消息和删除文件时的画面跳动；大屏设置切换时侧边栏边缘抖动；侧边栏当前对话的选中背景不显示，悬停时的时间不出现
- 修复：表格「复制图片」复制到别的消息里的表格；待发送的视频和图片分不清；Windows 上开着安卓屏幕切对话后界面定格；更新提示里同一条改动重复显示；侧栏更新按钮的图标错位；App 里 Gemini 的图标颜色不对
