- 新功能：把手机借给 agent 时，它在手机上开一块自己的虚拟屏幕干活，你可以照常用手机；通知里写明是哪个对话在用，10 分钟不用就自动关掉
- 新功能：能看到屏幕正被哪台设备占着，可以把它断开或改成只看；你让 agent 接管时，它能自己接过屏幕
- 新功能：Antigravity CLI 可以用 Google 账号登录，使用 Google AI Pro / Ultra 套餐
- 新功能：飞书和 Lark 的连接可以选「每个 thread 一个会话」：回复留在 thread 里，要 @ 才开会话；群里没被叫到、也没说话的 agent 不再留下「完成 · 用时」卡片
- 新功能：Windows 版把报错和性能记录写进本机的日志文件，可以在「关于」里打开日志文件夹
- 改进：左滑归档不再容易误触：上下滑列表时手指稍微偏左不会被当成左滑，轻轻一甩也不会归档，要划过一半再甩或拖过归档线松手；左滑露出的「归档」有了底色、不再压在图标上，长按对话时这一行会浮起来
- 改进：安卓上连续滑动列表时，每次刚开始滑的那几帧不再掉帧
- 改进：对话旁的远程桌面面板去掉重复的名字，头部并成一行，画面周围换成浅灰底；单独开在窗口里的屏幕，从对话链接等地方再打开时会到最前面，并随 app 一起关掉
- 修复：对话、连接、任务、编辑或其他工作区的会话多时，会话列表、查找最近对话、搜索、自动归档检查和删除对话变慢；用量页准备近期数据时先显示已有的年度历史；长的 Codex 对话往回翻历史每页不再要几秒
- 修复：station 崩溃后接管 Codex 会从头读几百 MB 输出、卡住十几秒；多个对话共用的 Codex 进程一直有轮次在跑时，输出文件无限增长；station 更新交接时旧进程可能崩溃、新进程卡住十几秒；过期的远程任务文件有时不再自动清理
- 修复：安全模式下批准或移除设备时，网络丢了回答也不再把成功的操作报成失败；面对面批准时不再误报「安全码不对」或「没能批准此设备」，显示安全码的设备断开会说明；只在部分 workspace 获批时，等待页说明还要谁来批准
- 修复：安全模式下网页版设备 30 天到期后可以重新批准；owner 用后来获批的设备也能把 station 加入安全模式；开启时没包括进去的 station 不再一直拒绝成员，在「设置 › 安全」点「保护」就能加进来；关掉又开启安全模式时，刚批准过设备或不在线的 station 不再被旧锁锁住；station 之间断线恢复后自己补齐锁的记录
- 修复：两台设备几乎同时改同一个密钥库时，各台 station 可能各存一版、一直对不上；手机和电脑判断密钥库可不可信现在和 station 用同一套规则
- 修复：归档页的搜索框不起作用，现在也能按对话里说过的内容搜到；有时其他设备创建的对话没出现在列表里；跨站分享的订阅账号重复显示
- 修复：用量页「Token 活跃度」一片空白、累计 token 显示 0；「按模型」、图例和日期筛选点了没反应；部分 ChatGPT 账号没显示额度重置卡的到期时间
- 修复：选模型浮窗里常用和喜欢的模型有时消失；打开时自动滚到已选的模型；新对话页打开时不再先出现在别处再跳走
- 修复：带 @ 引用对话的消息发送时露出原文、跳动或变色；agent 把同一个请求发了两次的对话一打开就显示「这部分显示出错了」；回复在等你处理的对话时「需要你处理」闪一下；后台任务里列出已经结束的任务
- 修复：多行输入框的提示文字显示不全；点输入框时误选中并滚动背后的消息；⌘K 里鼠标划过的行一直高亮；首页下拉时对话前的转圈跟那一行错开
- 修复：Mac 上文字偶尔变成重叠错位的碎块，桌面版长时间运行后部分文字变空白；内容多的页面偶尔整窗卡住几秒；Mac 上 WebM 和 VP9 视频只有声音没有画面；点系统通知重新打开聊天时可能闪退
- 修复：把手机借给 agent 时自己点输入框键盘可能不弹；安卓上在浏览器里登录完回不到 app；网页版缩放快捷键和触控板双指、Ctrl+滚轮缩放不起作用；station 更新后数据外流的 Tailcat 端口变化
