- 新功能：连接可以在页面上直接切换运行时

- 新功能：agent 自带等 GitHub CI 的方法，一项检查失败就立刻回来处理，不再自己写轮询空等
- 改进：允许对话调试你的手机现在要用你设备的个人密钥，由手机自己核对；第一次允许只按一次指纹或锁屏；新设备直接在卡片上加入个人锁，旧授权点一下就能确认；没开个人锁的设备会先提示开启，所有账号只要一个码、核对一次
- 改进：远程屏幕网络好时画面更清晰：码率上限约提高一倍，「自动」画质可以升到和「原画」一样高，网络恢复后清晰度回升更快
- 改进：Slack 里的登录卡片直接放登录页按钮，设备码写在卡片上，不用先打开 still.fail 网页；打开 Claude 授权页面前先确认一次
- 改进：station 更新失败时显示原因和处理方式；Codex 版本过旧时自动更新并继续对话
- 修复：新设备申请批准时收不到安全码或一直等待（网络短暂中断、受信任设备刚启动、安全记录或设备名单正在更新、请求无响应时）；现在点「发送批准请求」后每 10 秒找一次受信任设备，先点请求再打开手机或电脑上的 still.fail 也会弹安全码；开启安全模式后加入的成员申请批准时，管理员的设备也会弹安全码
- 修复：会话、后台服务、密钥请求或历史登录卡片多时，station 检查工作状态、恢复对话和待处理密钥、更新后启动、结束登录变慢或长时间等待
- 修复：部分早期版本的 station 数据库升级时打不开、中断后不能重试，或升级时长时间阻塞写入
- 修复：会话切换工作区后登录状态可能存不上；发出保存密钥请求时新加的设备可能无法批准
- 修复：把上下文上限改到比当前上下文还小时，这轮结束后就压缩，不再把完整上下文多发一次；卡片写明会压缩
