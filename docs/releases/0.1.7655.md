- 新功能：铃铛列出计入红点的所有未读对话，可以一键全部已读；手机首页也有铃铛
- 改进：账号页点头像就能更换，不再单独占一行
- 改进：安卓上左滑归档别人发起的对话前先确认：归档后 workspace 里所有人都看不到它；只想自己不看可以长按选「隐藏」
- 改进：屏幕很宽时，从左边缘右滑返回拖 120pt 就够，不用再拖过三分之一屏宽
- 修复：Claude Code 某个模型自身限额（如 Fable 每周上限）用完时，station 不再把整个账号当成没额度，只暂停这个账号上的这个模型约 1 小时、其他模型照常可用；提示写成「Fable 自身限额已用完（非账号额度）」，不再和账号额度用完混在一起
- 修复：旧会话消息变更或编辑记录很多时，写入和读取消息、侧栏、通知、自动归档检查和数据整理变慢；部分消息更新后侧栏的未读状态可能不准
- 修复：网络断开重连后，打开的对话可能一直不显示消息
- 修复：扫码创建飞书机器人后切出应用或 station 重启也能继续保存连接，保存失败会自动重试
- 修复：已有对话在小屏上改不了上下文长度
- 修复：触屏上侧边栏和对话并排时（展开的 Duo、iPad、安卓平板），切换对话后上一个对话的灰底要一秒多才消失、新对话的选中底色先闪一下再出现，现在平滑过渡
- 修复：部分设备上界面出错时没留下错误报告；错误报告里不再带文件路径
