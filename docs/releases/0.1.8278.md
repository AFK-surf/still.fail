- 新增：station 可以设为「只执行任务」：不运行 agent、不保存对话，只跑对话里 agent 发来的任务；对话要用它由所有者在卡片上批准并选时限，也可以对整个 workspace 免批准
- 新增：设备统一管理：接在 station 上的手机、开发板、摄像头、路由器、串口和成员的手机在一个「设备」列表里，归各自的所有者；agent 申请使用，手机授权可选闲置 1 小时或 8 小时
- 新增：still.fail 团队可以回复你提的问题反馈，回复显示在提反馈的对话里，可以直接回复或交给 agent
- 新增：对话的「文件」页列出个人收藏，以及每台 station 的主目录和磁盘
- 新增：Claude 订阅里 Fable 的每周独立额度显示在 Profile 里，用完只停 Fable；额度重置按种类分别列出、写明恢复哪部分，Claude 订阅也能用掉一次重置
- 新增：新设备的等待页列出在哪几台设备上打开 still.fail 能弹出安全码
- 改进：不再有「个人锁」：能批准手机调试的设备在「设置 › 共享调试」里查看和移除，新设备按「发送批准请求」获批
- 改进：选模型的面板重做：思考深度直接在面板里点或拖，常用搭配和收藏分开显示，每个模型旁都能加星
- 改进：更新只下载和当前版本的差异，通常只有整包的一到两成
- 改进：station 自动换账号（额度用完等）时，对话里会提示换到了哪个账号
- 改进：引用对话（@）先列你最近打开过的对话
- 改进：小屏上从抽屉里再打开下一层（分享、重命名、agent 卡片、上下文等）时在同一个抽屉里接上，带返回键
- 改进：切底栏、从对话返回首页、有多台 station 时更顺：不再每次整份接收 station 列表和更新日志、不再反复解码；首页不再一直测各 station 的网络；机器内存紧张或磁盘繁忙时 station 不再卡住
- 改进：弹出面板往下快速一甩就能关；展开收起中途被叫回时接着原来的速度过渡；执行历史的展开、收起平滑过渡
- 改进：键盘操作：设置等页面的翻页键和方向键能滚动，菜单关闭后焦点回到打开它的按钮，选图标可以用键盘
- 修复：安全模式下，移除成员或 station、改角色没有写进 workspace 锁；在第二个 workspace 开安全模式后其他设备不能签名、打不开密钥库；移除设备后它仍被放行；移除设备时密钥库换钥匙被打断或库所在的 station 离线，条目打不开或库消失
- 修复：同一账号的设备请求多时，新设备登录或之后的账号操作被拒（请求过于频繁）
- 修复：发消息、agent 发来卡片、agent 很快结束一轮、往上加载更早消息时消息列表跳动或闪烁；未读标记有时消不掉；打字后马上发送输入框停在半路
- 修复：执行历史在侧边面板里用触控板往上滚会被弹回底部，读更早一页时位置乱跳
- 修复：对话接力到 Slack 或飞书群后，有人在那里 @ 机器人会多出第二个 agent 一起回复
- 修复：连续发消息时安卓应用可能闪退；Mac 上从下载文件夹直接打开的 app 无法更新
- 修复：粘贴超过 8 MB 的截图没反应；Windows 控制远程屏幕时 Win+K 等组合键传不过去；预览里放大图片或视频后关闭的动画跳动
