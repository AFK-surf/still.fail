- 新增：添加 workspace 成员时会给对方发邮件，告诉对方被谁加进了哪个 workspace、怎么进来
- 新增：选择模型账号时可以勾选任意几个账号自动轮换（原「自动」改为「全选」）；Antigravity CLI 运行中可以插话纠偏，和 Devin 的同名模型合在一起并标明所属
- 新增：添加 station 时给出 Windows 原生（PowerShell）安装命令，不再要求 WSL；station 配置里可以写沙箱入口，agent 把构建和测试排到沙箱里跑
- 改进：所有 station 都离线时，对安全模式的修改先记下并列为「还没有生效」，station 上线后按先后自动生效
- 改进：对话有变化时只处理变了的那一行，对话列表和切换 workspace 更快；一个 chat 绑定大量 Slack thread 时 agent 不再随之变慢
- 改进：station 集中续期 Claude 订阅令牌，不再因同时刷新而掉登录；每个订阅账号在 station 浏览器里有自己的登录环境
- 改进：Windows 上第二次起启动更快，界面在动时和高刷新率屏幕上 CPU 占用更低
- 改进：平板上的弹层和提示条不再被系统状态栏、导航栏挡住；长按空格会选中旁边的词；预设指定了模型或 station 时新对话里不能再改
- 修复：Mac 上的 station 运行久了文件描述符耗尽、新连接失败；更新时端口被占用导致 station 离线；自动更新遇到临时错误会重试一次
- 修复：Codex 会话输出很大时 station 重启后反复被结束；设备连 station 偶尔被当成凭证错误断开；agent 改对话标题要等 3 分钟才生效
- 修复：读取飞书消息里的图片和文件失败，引用一条消息再问机器人时读不到被引用的内容
- 修复：安全模式下几项改动一起被挤掉后不再悄悄消失，会按先后重新生效；密钥库等待更换钥匙时反复要求验证身份；在一个 workspace 里改 Profile 可用的 station 会影响其他 workspace
- 修复：断线后重启时已读消息留在待处理；网络刚好切换时修改设置直接提示失败
- 修复：安卓分屏时点输入框不弹键盘、选图后进不了输入框、长按选中文字后按返回会收起键盘、折叠屏从通知进入后按返回直接退出
- 修复：Mac 休眠或息屏恢复后窗口画面卡住；本机装过 station 时无法在「添加 station」里加这台电脑
- 修复：中屏和大屏用鼠标按住列表拖动会被甩出去；快速滑动或甩到底时列表大片空白；切换页面时高度伸缩、闪帧；网页版在手机上长按输入框不能粘贴
- 修复：用量统计里 Gemini 等模型显示未计价
