1. 关于本条款

本条款是你和 still.fail 的运营者（一位位于中国大陆的个人开发者，下称“我们”）之间关于使用 still.fail 托管服务的约定。托管服务包括 still.fail 官网、网页版（app.still.fail）、公开分享页、预览页、中继服务器，以及连接这些服务时的桌面应用和 Android 应用（合称“本服务”）。测试渠道 youdid.wtf 也适用本条款。

你必须年满 16 周岁才能使用本服务。如果你代表公司或其他组织使用，你保证有权代表其接受本条款。

2. 本服务是什么

still.fail 让你在聊天中指挥运行在你自己机器上的 AI 编程 agent（如 Claude Code、Codex）。agent 运行在你或你的 workspace 成员安装的 station 上；本服务负责账号登录、workspace 管理、设备与 station 之间的连接和中继、推送通知等。

本服务目前免费。免费版限制 workspace 和成员数量，标准版通过邀请码或由我们开通。我们可以调整额度和套餐；将来如果开始收费，会提前告知，并另行约定收费条款，不会在你不知情时向你收费。

3. 账号

4. 你的 station 和 agent

station 上的 agent 以该机器上对应系统账号的权限执行命令、读写文件、访问网络和你配置的各种账号。agent 可能出错，可能删除或改错文件、执行你不希望的操作。你需要：

  • 在你信任的机器和系统账号上运行 station，必要时使用专门的账号或机器，并做好备份；
  • 只把你信任的人加入 workspace。workspace 成员资格是应用内的访问权限，不是操作系统级的隔离；
  • 检查 agent 的工作成果，对你在 station 上运行的东西、agent 代你执行的操作及其后果负责；
  • 遵守你在 station 上使用的第三方服务（如 Anthropic、OpenAI、GitHub、Slack）的条款，包括这些服务对订阅账号使用方式的限制。

我们不控制、不审查 agent 的输出，不保证 agent 的输出正确、完整、安全或适合你的用途。

5. 你的内容

你在本服务中输入、上传或让 agent 生成的内容（“你的内容”）归你或其原权利人所有。你的内容保存在你的 station 上，我们的服务器不保存聊天内容（例外情况见隐私政策第 3 节）。你授予我们为提供本服务所必需的、有限的处理权限，例如转发推送通知、保存你提交的问题反馈。

你公开分享的聊天，任何拿到链接的人都能查看。分享前请确认其中没有你不想公开的信息；你可以随时撤销分享。你保证你的内容不侵犯他人的权利，也不违反法律。
