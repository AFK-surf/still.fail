01 号池01 Account pool

账号放进一个池子，额度一点不浪费，Every account in one pool, no limit left unused,

每个 station 都有一个号池。新对话只在启用了所选模型的账号里挑，按「本周额度要花多快才不浪费」分摊：快重置、剩得多的号多分，但不会把所有对话压到一个号上。Every station keeps an account pool. A new chat is matched only to accounts with the chosen model, weighted by how fast each must spend its weekly limit so none is wasted: accounts that reset soon with more left get more, but no single account takes every chat.

自动挑号Picks the account

跳过登录失效、密钥被拒或额度用尽的号；5 小时额度用到 80% 的排在最后。额度每 5 分钟读一次。Skips accounts that are signed out, have a refused key or are out of quota; one at 80% of its 5-hour limit goes last. Quotas are read every five minutes.

换号不丢活Switches without losing work

进行中的对话尽量留在原账号。必须换时，agent 自己读回聊天记录；后台命令还在跑时不提前换。A running chat stays on its account where it can. When it must move, the agent reads back its own history, and it never moves early while background commands are still running.

station 之间共享Shared between stations

一台 station 可以把登录好的账号借给同一 workspace 的其他 station，没登录的电脑也能用团队的号。A station can lend its signed-in accounts to the other stations in its workspace, so a computer with no sign-in can still use the team's accounts.

密钥要你批准Keys need your approval

API 密钥加密存在密钥库里，agent 要用时，你在手机上点一下批准才交出去。API keys are kept encrypted in the vault. When an agent needs one, it's handed over only after you approve it on your phone.

安全Security

对话留在你的电脑上，Your chats stay on your own computers,

手机和电脑点对点连到你的 station，连不通时经加密中继转发。云端只管账号和中继，看不到内容。Phones and computers reach your stations peer to peer, and through an encrypted relay when they can't. The cloud only handles accounts and relays, and can't read your content.

点对点连接Peer to peer

设备之间先直接连接，连不通再走中继。不用配端口、VPN 或内网穿透。Devices connect directly first, and through a relay only when they can't. No ports, VPN or tunnels to set up.

数据在你的电脑上Data on your machines

对话、文件和记录存在 station 本地，不存在云端数据库里。Chats, files and history are stored on the station, not in a cloud database.

安全模式Security mode

打开后，成员、设备和 station 只有经可信设备签名才被接受，光靠云端放不进任何人。When on, members, devices and stations are accepted only when signed by trusted devices, so the cloud alone can't let anyone in.

密钥库Vault

agent 用的凭据加密保存，有人批准后才交出去。Credentials agents use are kept encrypted and handed out only after a person approves.

开源Open source · MIT 官方 CLIOfficial CLIs · 不改 agent，不绕过它们的限制agents unchanged, their limits respected 加密中继Encrypted relays · 只转发，看不到内容they pass data on without reading it

常见问题FAQ

问得最多的Asked most

号池怎么决定用哪个账号？How does the pool choose an account?

新对话只在启用了所选模型的账号里挑，跳过登录失效、密钥被拒或额度用尽的；5 小时额度用到 80% 的排最后。其余按「本周额度要花多快才不浪费」乘以 5 小时剩余额度分摊，快重置、剩得多的号多分。A new chat considers only accounts with the chosen model, skipping any that are signed out, have a refused key or are out of quota; those at 80% of their 5-hour limit go last. The rest share chats by how fast each must spend its weekly limit, times what's left of its 5-hour limit, so accounts that reset soon with more left get more.

中途换账号，会丢上下文吗？Does switching accounts lose context?

进行中的对话尽量留在原账号。原账号不能用了才换；要提前换，只挑上下文刚压缩过、或已接近压缩点的时候，agent 会读回之前的聊天记录。后台命令还在跑时不提前换。A running chat stays on its account where it can, and moves only when that account can't be used. It moves early only right after its context was compacted or when it is near the compaction point, and the agent reads its earlier history back. It never moves early while background commands are running.

和直接在终端里用 Claude Code 有什么不同？How is it different from Claude Code in a terminal?

终端里的 agent 只能坐在那台电脑前用。monoid 把你每台电脑上的 agent 放到一处：账号进号池，在手机或 Slack 里随时交代和查看，看每台电脑的负载，密钥在 agent 使用前由你批准。agent 本身不变。An agent in a terminal is used at that computer. monoid puts the agents on all your computers in one place: accounts share a pool, you direct and follow them from your phone or Slack, see each computer's load, and approve a key before an agent uses it. The agents themselves are unchanged.

要付费吗？Does it cost anything?

目前免费，套餐限制 workspace 和成员数量，每个 workspace 最多 64 台 station。agent 用的是你自己的订阅账号或 API 密钥。It's free for now. Plans limit workspaces and members, and each workspace can have up to 64 stations. Agents use your own subscriptions or API keys.

代码和对话会传到云端吗？Do my code and chats go to the cloud?

不会。对话、文件和记录保存在你的电脑上，云端只负责账号和中继。中继只转发加密数据，看不到内容。No. Chats, files and history stay on your computers; the cloud only handles accounts and relays. A relay passes on encrypted data it can't read.

电脑要一直开着吗？Does my computer have to stay on?

agent 在你的电脑上运行，所以电脑要开着、联网。station 随登录启动，不用开着窗口。Agents run on your computer, so it has to be on and online. The station starts at login; no window needs to stay open.

不在同一个网络里，能连上吗？Does it work across networks?

能。设备之间先直接连接，连不通时经加密中继转发，不用配置端口、VPN 或内网穿透。Yes. Devices connect directly, and through an encrypted relay when they can't. No ports, VPN or tunnels to set up.

会影响我的 agent 账号吗？Does it affect my agent accounts?

monoid 运行的是这些 agent 的官方命令行，和你在终端里用它们一样，不修改它们，也不绕过它们的限制。monoid runs each agent's official command-line tool, the same as you would in a terminal, without changing it or working around its limits.
