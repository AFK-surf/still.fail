Your chats stay on your computers

Devices reach your stations directly or by encrypted relay; the cloud can’t read your content.

  • Peer to peer

    No ports to open, no VPN, no tunnels.

  • Data on your machines

    Chats, files and history live on the station, not in a cloud database.

  • Security mode

    Once on, members, devices and stations need a trusted device’s signature. The cloud alone can’t add anyone.

  • Vault

    In security mode, the keys agents use stay encrypted until a person approves.

One command adds a computer

Stations run on macOS (Apple silicon), Linux (x64, arm64) and Windows (x64), with that computer's user permissions.

  1. 01Open the app and create a workspace
  2. 02Choose Add station and run its command on the computer
  3. 03Sign in to Claude Code or Codex; the account joins the pool

Asked most

How does the pool choose an account?

Among working accounts with the chosen model, those resetting soonest with the most left get more chats; one past 80% of its 5-hour limit goes last.

Does switching accounts lose context?

The agent reads its history back. A chat moves only when it must, or early around a compaction, never while background commands run.

How is it different from Claude Code in a terminal?

A terminal agent is tied to one computer. monoid gathers them all: pooled accounts, direction from your phone or Slack, keys you approve. The agents are unchanged.

Does it cost anything?

Free for now. Plans limit workspaces and members; a workspace holds up to 64 stations. Agents use your own subscriptions or API keys.

Do my code and chats go to the cloud?

No. Chats, files and history stay on your computers; relays pass on only encrypted data they can't read.

Is it open source?

Yes, under the MIT license. The code is on GitHub.
